# Искусственный интеллект и ML (Учебные модули)

В этой папке собраны реализации AI-моделей для решения прикладных задач:

1. **Predictive Maintenance (LSTM Autoencoder)** — система поиска аномалий в телеметрии оборудования по временным рядам.
2. **Doc Verification (NLP + OCR)** — FastAPI-сервис, который проверяет документацию по правилам ГОСТ и распознаёт кабели/сигналы.
3. **Equipment Recommender (CatBoost)** — ML-система, которая рекомендует модели датчиков по параметрам окружающей среды.

📌 Все модели написаны на Python, используют `PyTorch` и `scikit-learn`.
