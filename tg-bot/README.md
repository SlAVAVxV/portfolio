# Telegram-бот "Синергия"
Информационный бот для абитуриентов Университета «Синергия» на Python.

### 🛠️ Функционал:
- Выдача контактных данных (телефон, почта, сайт).
- Информация о корпусах (адреса, метро, карты).
- Консультация по приёмной комиссии (документы, особенности).
- Панель администратора для просмотра статистики пользователей.

### 📚 Технологии:
- `python-telegram-bot` (работа с API)
- `sqlite3` (хранение данных и логов)
- `Docker` (контейнеризация)
