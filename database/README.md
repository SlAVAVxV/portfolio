# Схема базы данных «Туризм»
Реляционная база данных для туристического агентства.

### Таблицы:
- `Clients` (Клиенты)
- `Tours` (Туры)
- `Services` (Дополнительные услуги)
- `Orders` (Заказы)
- `Ordered_Services` (Заказанные услуги)

🔗 Реализованы связи внешних ключей (`FOREIGN KEY`), обеспечена нормализация данных.
